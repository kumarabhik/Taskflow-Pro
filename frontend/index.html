Quick start

  1. Drop CSVs in ./data/: members.csv, tasks.csv, inventory.csv (auto-created if missing).
  2. Edit inline. Columns are fixed to keep schema stable during your demo.
  3. Plan sprints (Greedy / Knapsack) by capacity.
  4. Watch Inventory Alerts for at-risk SKUs.
  5. If auth/RBAC is enabled, set your email + API key in Collab Notes.
